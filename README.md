# linked-shelf

国立国会図書館（NDL）のデータをベースにした、グラフ構造に基づく探索型のデジタル本棚Webアプリケーションです。
単なるフラットな検索結果のリスト表示ではなく、「物理的な本棚を眺めるような偶発的な出会い（セレンディピティ）」と「知識の旅」をブラウザ上で実現することを目指しています。

デモサイト: [https://asamika.github.io/linked-shelf/](https://asamika.github.io/linked-shelf/)

---

## 🌟 コンセプト

- **空間的セレンディピティ:** 物理的な書架で隣り合った本に目が留まるように、予期せぬ書籍との出会いを演出します。
- **グラフ構造によるナビゲーション:** 隣の棚、別の年代、異なるテーマ、あるいは思いがけない「回り道（ワープ）」の通路を伝って、広大な知識空間をシームレスに散策できます。

---

## 🏗️ コアアーキテクチャ

GitHub Pagesで動作する軽量なSPA（シングルページアプリケーション）として設計されており、拡張性と軽快な動作を両立するため **「ノード・エッジ・グラフモデル」** を採用しています。

### 1. `ShelfNode`（棚・キャッシュ）
各ノードは1つの「棚」を表し、具体的な書籍メタデータ（キャッシュ）と、そこから伸びるエッジのリストを保持します。
```json
{
  "id": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
  "books": [
    { "title": "量子力学入門", "color": "#191970", "pubYear": 1990 }
  ],
  "edges": [...]
}
```
## 2. Edge⁠（レシピ・アクション）
エッジは固定のリンクや重いクロージャではなく、シリアライズ可能な「アクション名 ＋ 引数（レシピ）」のデータ構造として保持されます。これにより、状態の保存・履歴管理、さらには「振り返る」「通路に入る」「遠くへジャンプする」といった多次元的な遷移を柔軟に実現できます。

```json
{
  "label": "右の棚へ ▶",
  "action": "fetchShelfNode",
  "args": { "targetId": "node-2" }
}
```

├── README.md                 # プロジェクトの解説と方針（作成済み）
